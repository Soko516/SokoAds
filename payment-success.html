SOKOADS v2 — PesaPal-ready live app This project has been updated into a live marketplace app with server-side payment flow and secure environment configuration. Features: - Express backend with health check and public API routes - ads creation and listing flow - PesaPal API 3.0 authentication, order submission, and transaction status verification - callback and IPN handling - admin password login - deployment config for Render Environment variables: - PORT=3000 - PUBLIC_BASE_URL=https://your-domain.com - PESAPAL_ENV=SANDBOX or LIVE - PESAPAL_CONSUMER_KEY=... - PESAPAL_CONSUMER_SECRET=... - PESAPAL_IPN_ID=... - ADMIN_PASSWORD=... Local run: 1. npm install 2. cp .env.example .env 3. fill in your real values 4. npm start 5. open http://localhost:3000 Production setup: - deploy to Render or any HTTPS Node host - set PUBLIC_BASE_URL to your live domain - register the public IPN URL in the PesaPal dashboard - copy the returned ipn_id into PESAPAL_IPN_ID - switch PESAPAL_ENV=LIVE and use live credentials only for production Important: - never put consumer secret or payment credentials in browser code - use HTTPS in production - live payments will only succeed when the app is deployed on a public HTTPS URL and the real PesaPal keys are configured PesaPal docs: https://developer.pesapal.com/
